Product brief

Faster, more trustworthy answers from business data

A portfolio prototype for a fictional Indian fashion wholesaler. The sample ends on 28 October 2026, so October is partial and 2026 totals are year-to-date. It pairs a read-only dashboard with a guided, evidence-first assistant so a business owner can answer routine questions without waiting for an analyst.

Who this is for

A wholesale business owner or product and operations lead who works with sales and factory teams but has no analyst available for every question.

The problem

Simple questions about sales, returns and production can take hours or days when someone must export a spreadsheet, define the metric and prepare a report.

Product approach

Let users filter the same source data and ask common questions in plain language. Show the answer, date window, filters and calculation. Offer follow-up questions. Charts cross-filter when selected; a click opens matching order-line detail. Hover tooltips show values and share. Unsupported requests are declined instead of guessed.

The current free assistant uses fixed question patterns and local calculations. It is not a general-purpose AI model. Example questions help users discover what it supports. There is no live database connector; all sample data is embedded in the page.

How success would be measured

Time to answerTarget: median under 30 seconds for supported questions. Measure from question submit to answer shown.
Answer correctnessTarget: at least 95% on the 30-question evaluation set before inviting users. Re-run after changes to metrics or parsing.
User trustTarget: at least 4 out of 5 on “I can verify this answer.” Collect a simple helpful/not-helpful rating and optional reason.

Scope and decisions

Included: sales, gross profit, returns, buyer activity, product and market comparisons, and monthly factory output. These support follow-up on quality checks, assortment, coverage and production planning.

Left out: inventory, stockouts, lead times, true return reasons, receivables and forecasting. Without those inputs, the dashboard cannot make a reliable restock recommendation or explain a root cause.

Risks and guardrails

  • Every answer should show its period, active filters, metric definition and source values.
  • Unsupported questions should return “I can’t answer that from this data.”
  • Return and margin alerts are review signals, not proof of cause. The sample has no return-reason or defect-to-order links.
  • All records are synthetic. The assistant uses fixed question patterns and local calculations. It sends no data to an AI service. This keeps answers inspectable, data in the browser and running costs at zero.
Production output is generated per month and SKU at 7–15% above shipped units. Facility assignment is simulated; there are no work-order or inventory roll-forward links, so it is not a reconciled ERP record.

Evaluation

The strengthened 30-question core set scored 30/30, checking every monthly value, ranking order and underlying ranked value. A separate 12-question development set first scored 9/12. Its misses—ranking a month by gross profit, return-percentage wording and city-level sales—were used to improve the assistant; it now passes 12/12 as a regression check. This is no longer a blind test. The original prototype scored 28/30 under a looser check on different data, so those scores are not directly comparable.
